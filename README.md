### About

I am a Computer Science undergraduate at **NIT Rourkela** (B.Tech, class of 2029) with a focus on backend engineering and distributed systems.

I learn by building production-style systems end to end, with particular attention to how they behave under failure: delivery guarantees, retries, idempotency, leases, and crash recovery. Significant design decisions in my projects are recorded as Architecture Decision Records, documenting the alternatives considered and the trade-offs accepted.

- Currently building **Helmrun**, a distributed platform for executing AI agents reliably
- Designing **Tessera**, a distributed video processing pipeline
- Practising data structures and algorithms consistently alongside project work

<table>

<td width="50%" valign="top">

#### Helmrun &nbsp;<sub>`In development` · `Private`</sub>

A distributed platform for executing AI agents, featuring asynchronous scheduling, multi-provider LLM support, MCP and tool integration, isolated runtimes, durable run state, retries, cancellation, checkpointing, and crash recovery.

**Architecture highlights**
- PostgreSQL as the single source of truth
- Amazon SQS behind a transactional outbox for at-least-once delivery
- One isolated Kubernetes Job per execution attempt
- SSRF-hardened HTTP tooling
- End-to-end tracing with OpenTelemetry

`TypeScript` `Node.js` `PostgreSQL` `SQS` `Kubernetes` `Redis`

A distributed video processing platform that accepts large uploads, transcodes them into multiple quality levels, and prepares them for reliable streaming through horizontally scalable background workers.

**Focus areas**
